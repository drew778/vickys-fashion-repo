VICKY'S FASHION — Website
=================
A self-contained static website. No build step, no server needed.

TO PREVIEW:  open  index.html  in any web browser.
TO PUBLISH:  upload the entire contents of this folder to any static host
             (Netlify, Vercel, Cloudflare Pages, GitHub Pages, or your own).

PAGES
  index.html          Home
  fabrics-suits.html  Suiting catalogue (procedural weave swatches)
  fabrics-shirts.html Shirting catalogue
  swatches.html       Swatch Library — real cloth captured from your books + full book gallery
  lookbook.html       Portfolio gallery
  studio.html         The Design Studio — dress a men's/women's model in real cloth,
                      choose lining, piping, buttons
  about.html          Atelier / story / process
  contact.html        Book-a-fitting form (emails hello@vickysfashion.com)

EDIT NOTES
  • Brand name, address, email, phone: search the .html files for
    "Vicky's Fashion", "your city", "hello@vickysfashion.com" and replace as needed.
  • Fabric list / colours: assets/js/fabrics-data.js
  • Weave rendering: assets/js/pattern.js
  • Captured swatches: assets/img/swatches/ (+ assets/js/swatches-data.js)
  • Fonts load from Google Fonts (needs internet); falls back gracefully offline.
  • Your personal "Drew Coleman" monogrammed items and shipping label were excluded.
